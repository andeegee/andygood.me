## Important implementation notes

- Preserve the client work as-is.
- Do not recolour, add mock browser chrome into the source images, or place Andy Good branding over client work.
- Any framing, borders or background surfaces should be created in CSS using the approved Andy Good visual identity.
- Use object-fit / responsive wrappers rather than destructive cropping in code where possible.
- Dreamscape Tents should remain text-led until a genuine screenshot or original project asset is supplied.
- Do not use the BITA / Net Hub case study on the Work page.
